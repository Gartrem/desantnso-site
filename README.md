# Союз десантников Новосибирской области — сайт-визитка

Статический одностраничный сайт для РОО ВДВ «Союз десантников Новосибирской области» имени полковника Ильина Анатолия Григорьевича.

## Запуск локально
Откройте `index.html` в браузере или запустите простой статический сервер.

## GitHub Pages
Сайт не требует сборки. Публикация выполняется автоматически через GitHub Actions после обновления ветки `main`.

Публичный адрес: https://gartrem.github.io/desantnso-site/
